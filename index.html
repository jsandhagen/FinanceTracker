Your accounts

1 · Download from Capital One

The download form opens on CSV and Last 30 Days. If an account above is less than four weeks behind, that is already right: press Download. Otherwise pick a longer Time Period. Overlap is fine: anything already saved is skipped.

To skip the clicking around: open an account on Capital One, copy the address from the address bar, and save it here with Add link. Any page of the account works; the button then opens that account's download form directly.

Settings

Text size

Makes everything larger or smaller on this device. Wide windows already scale up by themselves.

Sync between devices

Optional. Keeps your phone and computer in step through a secret GitHub Gist. Everything is encrypted on this device with your passphrase before it is uploaded, so GitHub only ever stores unreadable data. You need a GitHub personal access token with the gist scope. Use the same token and passphrase on every device.

Credit card starting balance

The balance on the card at the start of your oldest credit card export. Fixes the card balance line on the net worth chart.

Category rules

Created when you recategorize a transaction. Tap ✕ to remove one.

Backup

A plain (unencrypted) file with every transaction and rule, for safekeeping or moving to a new device without sync.
