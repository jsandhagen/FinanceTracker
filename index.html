Settings

Sync between devices

Optional. Keeps your phone and computer in step through a secret GitHub Gist. Everything is encrypted on this device with your passphrase before it is uploaded, so GitHub only ever stores unreadable data. You need a GitHub personal access token with the gist scope. Use the same token and passphrase on every device.

Credit card starting balance

The balance on the card at the start of your oldest credit card export. Fixes the "CC outstanding" line on the assets chart.

Category rules

Created when you recategorize a transaction. Tap ✕ to remove one.

Backup

A plain (unencrypted) file with every transaction and rule, for safekeeping or moving to a new device without sync.
